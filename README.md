# 🛒 E-Commerce Customer Churn Analysis

Overview
Analyzed 5,630 customer records to identify churn 
patterns and provide actionable business recommendations
for customer retention.

 Dataset
- Source: Kaggle E-Commerce Customer Churn Dataset
- Total customers: 5,630
- Churned customers: 948 (16.8%)

 Business Questions Answered
1. What is the overall churn rate?
2. Do complaints cause higher churn?
3. Which city tier loses most customers?
4. How does satisfaction score affect churn?
5. What are the top retention strategies?

 Tools Used
- Google Sheets — data cleaning and analysis
- Formulas: COUNTIF, COUNTIFS, COUNTA, AVERAGE
- Charts: Pie, Bar, Column charts

 Key Findings
- Churn rate: 16.8% — above industry benchmark
- 508 complainers churned vs 440 non-complainers
- Tier 1 cities show highest churn (532 customers)
- Score 3 satisfaction has surprisingly highest churn
- Recommendation: Fast complaint resolution is #1 
  retention lever


 Skills Demonstrated

- Google Sheets formulas — COUNTIF, COUNTIFS
- Data visualization — 4 professional charts
- Business insight generation
- Dashboard design
